# roadmap-sync

## 目的

ExecPlan や作業完了後に `ROADMAP.md` を最新状態へ同期する。

## 使うタイミング

- 新しい ExecPlan を作成したとき
- マイルストーンの状態が変わったとき
- 項目分割や順序変更が必要になったとき

## 手順

1. 対象 ID の状態を `未着手` `進行中` `完了` `保留` から選ぶ
2. 対応 ExecPlan パスを更新する
3. 依存関係とメモが現状と矛盾していないか確認する
4. `最終更新` を日本時間で更新する

## 注意点

- 進捗を先回りして完了扱いしない
- SSOT は `ROADMAP.md` とし、他文書の進捗記述とずれたらこちらを直す
