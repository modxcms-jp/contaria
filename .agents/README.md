# AIエージェント運用メモ

このディレクトリには、このリポジトリで使うスキルとサブエージェントの最小構成を置きます。

## 方針

- まずスキルを使い、定型ワークフローを再利用する
- サブエージェントは必要時だけ使う
- 書き込み責任は親エージェントが持つ
- サブエージェントは調査、レビュー、観点抽出などの read-heavy タスクに限定する

## ディレクトリ

- `skills/`: 再利用ワークフロー
- `subagents/`: 補助エージェント設定

モデルや推論量は、まず親エージェント設定を継承する前提にしています。コストや難易度に応じて、必要なものだけ個別に上書きしてください。

## 推奨順

1. `execplan-author`
2. `execplan-review`
3. `requirements-trace`
4. `roadmap-sync`
5. `japanese-doc-editor`

## サブエージェントの使いどころ

- `repo-researcher`: 対象ファイル、依存、既存仕様の調査
- `test-gap-reviewer`: 未検証ケースと回帰リスクの抽出
- `security-reviewer`: CSRF、二重送信、添付、設定露出などの確認観点抽出
