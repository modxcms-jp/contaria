# japanese-doc-editor

## 目的

日本語文書の文体、用語、構造を整え、英語混在や冗長さを抑える。

## 使うタイミング

- `AGENTS.md`, `PLANS.md`, `ROADMAP.md`, ExecPlan, README を編集するとき
- AI 生成文の言い回しを自然な日本語へ整えたいとき

## 手順

1. 正本ファイルを確認する
2. 用語の揺れ、重複説明、不要な英語表現を洗う
3. 見出し構造と箇条書きの粒度をそろえる
4. 具体性を落とさずに短く直す

## 注意点

- 仕様を変えずに表現だけを整える
- 日本語化を優先するが、識別子やコマンドはそのまま残す
